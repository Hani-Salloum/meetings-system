# Admin Routes Documentation

هذا الملف يوثق جميع المسارات المتاحة للمدراء في النظام.

## Users Management (`/admin/users`)

### الصلاحيات المطلوبة:
- `user:read-all` - قراءة جميع المستخدمين
- `user:read` - قراءة مستخدم واحد
- `user:create` - إنشاء مستخدم جديد
- `user:update` - تحديث مستخدم
- `user:delete` - حذف مستخدم
- `user:toggle-active` - تبديل حالة المستخدم

### المسارات المتاحة:

#### 1. الحصول على جميع المستخدمين
- **المسار:** `GET /admin/users`
- **الصلاحية:** `user:read-all`
- **الوصف:** يعيد قائمة بجميع المستخدمين مع التصفح والتصفية والترتيب
- **المعاملات:** `page`, `pagesize`, `filters`, `sort`, `search`, `joinOperator`

#### 2. الحصول على مستخدم واحد
- **المسار:** `GET /admin/users/:id`
- **الصلاحية:** `user:read`
- **الوصف:** يعيد معلومات مستخدم واحد بناءً على المعرف
- **المعاملات:** `id` (في المسار)

#### 3. إنشاء مستخدم جديد
- **المسار:** `POST /admin/users`
- **الصلاحية:** `user:create`
- **الوصف:** ينشئ مستخدم جديد في النظام
- **المعاملات:** `first_name`, `last_name`, `email`, `password`, `language`, `user_type_ids`

#### 4. تحديث مستخدم
- **المسار:** `PUT /admin/users/:id`
- **الصلاحية:** `user:update`
- **الوصف:** يحدث معلومات مستخدم موجود
- **المعاملات:** `id` (في المسار), `first_name`, `last_name`, `email`, `language`, `user_type_ids`

#### 5. حذف مستخدم
- **المسار:** `DELETE /admin/users/:id`
- **الصلاحية:** `user:delete`
- **الوصف:** يحذف مستخدم من النظام
- **المعاملات:** `id` (في المسار)

#### 6. تبديل حالة المستخدم
- **المسار:** `PUT /admin/users/:id/toggle-active`
- **الصلاحية:** `user:toggle-active`
- **الوصف:** يبدل بين الحالة النشطة وغير النشطة للمستخدم
- **المعاملات:** `id` (في المسار)

#### 7. الحصول على أنواع المستخدمين
- **المسار:** `GET /admin/users/types`
- **الصلاحية:** `user:read`
- **الوصف:** يعيد قائمة بجميع أنواع المستخدمين المتاحة للتعيين

## ملاحظات عامة:

### التصفح والتصفية:
جميع المسارات التي تعيد قوائم تدعم:
- **التصفح:** `page` و `pagesize`
- **الترتيب:** `sort` مع تحديد الحقل والاتجاه
- **البحث:** `search` للبحث في الحقول النصية
- **التصفية:** `filters` مع عمليات مختلفة (equals, contains, gt, lt, إلخ)

### معالجة الأخطاء:
جميع المسارات تتضمن:
- رسائل خطأ واضحة باللغتين العربية والإنجليزية
- رموز حالة HTTP مناسبة
- تحقق من الصلاحيات
- تحقق من صحة البيانات

### الأمان:
- جميع المسارات تتطلب مصادقة (JWT token)
- التحقق من الصلاحيات لكل عملية
- حذف البيانات الحساسة من الاستجابات
