## 7️⃣ الوضع الداكن (Dark Mode)

- جميع المتغيرات السابقة لها قيم بديلة داخل `.dark { ... }` لضبط الألوان في الوضع الليلي.
- مثال:
  - `--background` يصبح `240 10% 3.9%`
  - `--foreground` يصبح `0 0% 98%`

---

## 8️⃣ الأزرار (Buttons)

**أنواع الأزرار:**

| الكلاس          | الاستخدام              |
| --------------- | ---------------------- |
| `.btn`          | الزر الأساسي (Base)    |
| `.btn-blue`     | زر بلون أزرق أساسي     |
| `.btn-error`    | زر للتحذيرات أو الحذف  |
| `.btn-cancel`   | زر إلغاء               |
| `.btn-add`      | زر إضافة               |
| `.btn-outlined` | أزرار بإطار بدون خلفية |
| `.btn-text`     | أزرار نصية بدون خلفية  |

كل زر له نسخة `-outlined` ونسخة `-text`.

---

## 9️⃣ الجداول (Tables)

- `.emp-table` → لتصميم الجداول
- `th` → رؤوس الأعمدة بخلفية داكنة ونص أبيض
- `.footer` → تذييل الجدول
- `.rounded-md` → تعديل الحواف

---

## 🔟 مكونات إضافية

- `.dir-rtl` → دعم الاتجاه من اليمين لليسار
- `.transparent-input` → حقول إدخال بخلفية شفافة
- `::-webkit-scrollbar` → تخصيص شريط التمرير
- `.mySwiper3` → إعدادات مكون الـ Swiper
- `.animate-spin` → أنيميشن دوران

## 📌 ملاحظات

- استخدم المتغيرات بدل الأكواد المباشرة لتسهيل تغيير الثيم لاحقًا.
- جميع القيم مبنية على نظام HSL مما يسهل ضبط الـ Lightness و Saturation.
- عند إضافة مكون جديد للداشبورد، حاول الالتزام بنفس الألوان والمتغيرات.
