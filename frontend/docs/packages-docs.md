# Project Dependencies Explanation

This document explains the purpose of each package currently listed in your `package.json`.

---

## Core Framework & Utilities

- **next**: React framework for server-side rendering, routing, and static site generation.
- **react** / **react-dom**: Core React library and DOM bindings for building user interfaces.
- **typescript**: Adds TypeScript support for static typing in JavaScript.

---

## Styling & UI

- **tailwindcss**: Utility-first CSS framework for rapid UI development.
- **prettier**: Code formatter for consistent code style.
- **prettier-plugin-tailwindcss**: Sorts Tailwind classes in Prettier.
- **postcss**: Tool for transforming CSS with JavaScript plugins.
- **clsx**: Utility for conditionally joining classNames.
- **class-variance-authority**: Utility for managing complex className logic.
- **lucide-react**: Icon library for React.
- **country-flag-icons**: SVG flag icons for countries.
- **tailwind-merge**: Utility to intelligently merge Tailwind CSS classes.
- **tailwindcss-animate**: Tailwind plugin for animation utilities.

## Forms & Validation

- **react-hook-form**: Library for managing form state and validation in React.
- **@hookform/resolvers**: Integrates external validation libraries (like Yup/Zod) with react-hook-form.
- **@hookform/devtools**: Devtools for react-hook-form.
- **yup**: Schema validation library.
- **zod**: TypeScript-first schema validation library.
- **input-otp**: OTP (One-Time Password) input component.
- **react-phone-number-input**: Phone number input with formatting/validation.

---

## Data Handling & State Management

- **zustand**: Lightweight state management for React.
- **js-cookie**: Simple cookie handling for the browser.
- **qss**: Query string serializer and parser.
- **immutability-helper**: Helper for immutable state updates.
