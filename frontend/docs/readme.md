## 🚀 كيفية المساهمة

إذا كنت تريد إضافة توثيق جديد أو تحسين التوثيقات الموجودة:

1. أنشئ ملف Markdown جديد في هذا المجلد
2. اتبع نفس نمط التوثيق الموجود
3. أضف رابط للتوثيق الجديد في هذا الملف
4. تأكد من أن التوثيق شامل وواضح

## 📝 معايير التوثيق

### هيكل الملف

````markdown
# اسم المكون/الأداة

## نظرة عامة

وصف مختصر للمكون أو الأداة

## المميزات

- ✅ مميزة 1
- ✅ مميزة 2

## الاستخدام الأساسي

```tsx
// مثال على الاستخدام
```
````

## الخصائص (Props)

جدول بالخصائص المدعومة

## أمثلة

أمثلة عملية للاستخدام

## أفضل الممارسات

نصائح للاستخدام الأمثل

## استكشاف الأخطاء

حلول للمشاكل الشائعة

